Ověření integrity staženého souboru

Otisk staženého souboru musí odpovídat řádku v tabulce (PowerShell, i v Azure Cloud Shellu):

Get-FileHash .\deploy-azure.ps1 -Algorithm SHA256

Skript deploy-azure.ps1 si aktuální release balíček stahuje sám a při opakovaném spuštění instanci bezpečně aktualizuje (nastavení Function App zachová).
