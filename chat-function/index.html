Automatické aktualizace (od verze 1.9)

Instance nasazená skriptem deploy-azure.ps1 si jednou denně (01:30 UTC) ověří na tomto CDN podepsaný manifest svého kanálu (výchozí stable) a novou verzi si připraví; projeví se při příštím restartu instance. Balíček se použije jen tehdy, když manifest nese platný podpis EasyPortal365 a sedí jeho velikost i otisk SHA-256. Stav ukazuje GET /api/version vaší funkce; vypnutí: skript znovu s -AutoUpdate off.

Ověření integrity staženého souboru

Otisk staženého souboru musí odpovídat řádku v tabulce (PowerShell, i v Azure Cloud Shellu):

Get-FileHash .\deploy-azure.ps1 -Algorithm SHA256

Skript deploy-azure.ps1 si aktuální release balíček stahuje sám a při opakovaném spuštění instanci bezpečně aktualizuje (nastavení Function App zachová).

Kapacita modelu Azure OpenAI

Model deployment AI Asistenta potřebuje kapacitu alespoň 100K TPM – v Microsoft Foundry (dřív Azure AI Foundry) pole Tokens per Minute Rate Limit v Deployments. U pay-per-token nasazení (DataZoneStandard, GlobalStandard, Standard) to nic nestojí: platí se za spotřebované tokeny, ne za tento strop. Skript deploy-azure.ps1 nastavuje 100K jako výchozí a u deploymentu, který sám spravuje, nižší kapacitu dorovná (nestačí-li kvóta, jen upozorní). S parametrem -AzureOpenAiEndpoint (vaše vlastní Azure OpenAI) ji ale nekontroluje a šablona main.json deployment modelu nezakládá – tehdy kapacitu ověřte ručně.
