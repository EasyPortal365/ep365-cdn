SharePoint Capture

Doplněk do Chrome / Edge · EasyPortal 365

Uloží obsah SharePoint Online stránky jako PDF nebo PNG — čistě jen obsah, bez horní lišty, navigace, command baru a patičky.

Stáhnout ZIP
SharePoint-Capture.zip · ~134 KB · Manifest V3

Instalace (Chrome / Edge)

  1. Stáhněte SharePoint-Capture.zip a rozbalte do trvalé složky (např. Dokumenty\SharePoint-Capture).
  2. Otevřete chrome://extensions (v Edge edge://extensions).
  3. Vpravo nahoře zapněte Režim pro vývojáře.
  4. Klikněte Načíst rozbalenou a vyberte rozbalenou složku (tu s manifest.json).
  5. Hotovo — v liště se objeví ikona rámečku.
Jak na to: na SharePoint stránce klikněte pravým tlačítkem a zvolte „Uložit stránku do PDF (jen obsah)" nebo „…jako obrázek PNG (jen obsah)". Stejné volby najdete i po kliknutí na ikonu doplňku; rychlá zkratka je Ctrl + Shift + Y.
